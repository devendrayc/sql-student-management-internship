Student Management Database – SQL Internship Task 1

📌 Project Overview

This project was completed as Task 1 of my Data Analysis Internship at Maincrafts Technology.

The objective of this task was to design and work with a Student Management Database using SQL, while practicing database creation, data insertion, data modification, filtering, grouping, and basic analytical queries.

🛠️ Technologies Used

- SQL
- Relational Database Concepts
- Aggregate Functions
- Data Analysis Queries

📊 Key Activities

- Designed a Student Management database
- Created a structured Students table
- Inserted sample student records
- Retrieved and filtered data using "SELECT" and "WHERE"
- Used "GROUP BY" for categorized analysis
- Applied aggregate functions such as "AVG()" and "COUNT()"
- Identified the top-performing student
- Performed subject-wise performance analysis
- Analyzed grade-wise student distribution
- Practiced "UPDATE" statements for data modification

📂 Project Files

File| Description
"StudentManagement_Task1.sql"| Complete SQL database creation, sample data, and queries
"StudentManagement_Task1_Report.pdf"| Project report containing the methodology, queries, and findings

🎯 Key Learning

This project helped me strengthen my practical understanding of SQL and demonstrated how structured data can be queried and analyzed to generate meaningful insights.

📈 Key Insight

The analysis showed differences in subject-wise student performance and demonstrated how SQL aggregation and grouping can be used to identify useful patterns in student data.
